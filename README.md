# Medical-Insurance-Cost-Prediction
The application demonstrates how regression-based machine learning can be applied to a real-world problem — estimating healthcare costs — and made accessible through a simple, interactive web interface.

Technologies Used
Python – Core programming language
Flask – Web application and user interface
Pandas – Data loading, cleaning, and preprocessing
NumPy – Numerical calculations
Scikit-learn – Machine learning model development and evaluation
Matplotlib – Data visualization
Seaborn – Statistical data visualization
HTML/CSS – Front-end web interface
Jupyter Notebook – Data exploration and model development
Git & GitHub – Version control and project hosting
